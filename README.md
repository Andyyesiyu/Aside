# 旁白 · Aside 0.11.6

随手记录，陪你思考。

一个本地运行的 macOS 原生桌面便笺应用，原名「桌边 · DeskNotes」。当前提供自由贴纸与苹果备忘录同步，AI 功能尚在规划中。纸张配色、细边框和紧凑顶边参考 ryOS Stickies；正文使用 **Geneva + Fusion Pixel 简体中文，14 pt**（对应 macOS 界面的 14 个逻辑像素，Retina 屏幕不缩小为 7 pt）。

## 0.11.6 图标右键菜单

右键屏幕边缘图标可使用与顶部菜单栏相同的操作：新建、显示／隐藏、折叠全部、切换便笺、恢复已收走便笺、关联／同步备忘录、导出、设置和退出。移除原先单独的固定模式菜单项；⌘ 点击全部固定展开／隐藏的操作保留。

## 0.11.5 Command 点击

按住 ⌘ 点击屏幕边缘图标，可全部展开便笺并保持显示；再次 ⌘ 点击全部隐藏并退出固定模式。入口仍保留，普通点击与拖动不变。这里展开已有便笺，不改变其位置和尺寸。

## 0.11.4 标题编辑

光标移到标题文字开头，按一次退格可取消标题格式、恢复正文，不会删除文字或与上一段合并；支持撤销和重做。也可通过“格式 → 正文”恢复。再次输入井号和空格可重新设置标题级别。

## 0.11.3 固定模式

右键点击屏幕边缘图标，勾选“固定模式（全部展开并保持显示）”，展开所有未收走便笺并暂停自动隐藏。图标保持可见，可再次右键取消；原有自动隐藏偏好和每张便笺的钉住状态不变。模式会保存，重启后继续生效。手动使用显示/隐藏快捷键隐藏全部时会退出固定模式。

## 0.11.2 修复

数字列表允许直接修改编号；删除数字或整个编号前缀后，保存与刷新不再恢复旧序号或改动后面的数字。未完成的编号保留原文，取消编号后回车不恢复列表。自定义编号仍遵循备忘录格式回写保护。

## 0.11.1 修复

修复便笺底部连续输入时上下抖动：统一系统自动调整编辑区高度和末行留白的规则。新增五档缩放下的中间滚动位置回归，保留末行可见性和手动向上阅读行为。

## 打开与使用

双击同目录的 `Aside.app`。当前二进制适用于 Apple Silicon，macOS 13 或更高版本。应用驻留菜单栏，不占用 Dock。通过菜单栏的便笺图标进入新建、设置、备忘录连接、导出和退出。

- 面板收起时，屏幕边缘上方约四分之一处显示一个叠纸、折角和阴影的黄色便笺图标；点击展开，展开后图标隐藏。入口跟随左右停靠和显示器设置，不抢键盘焦点；没有便笺时点击可新建。
- 默认收起；点击屏幕边缘的便笺图标展开。鼠标碰到边缘不会展开。
- 鼠标移出便笺及四周 72 pt 保留区域约 0.65 秒后开始收起，动画约 0.2 秒；在便笺内编辑、拖动或使用菜单时保持展开。设置中可以关闭“移出后自动收起”。收起动画开始后，鼠标移回不会自动展开，需要再次点击图标。

- `⌃⌥N`：手动显示或隐藏便笺。
- `⌘N`：在应用内新建便笺。
- 直接编辑正文，自动保存在本机；支持中文输入、粘贴和系统撤销/重做。
- 自动识别网址和邮箱，显示蓝色下划线。⌘点击打开，右键可打开链接或复制地址。网址使用系统默认浏览器，邮箱使用默认邮件应用。编辑或粘贴后重新识别，旧便笺重开后也会识别。链接装饰不改变正文或同步格式。
- 双击顶边折叠，拖动顶边改变顺序。右侧停靠时拖动左下角，左侧停靠时拖动右下角，可独立调整这张便笺的宽度和高度。
- 右键菜单可换纸张颜色、插入时间或关联备忘录。“便笺大小”可选小、中、大或恢复默认；各张尺寸分别自动保存。设置里的“默认宽度”适用于尚未单独调整的便笺。
- 左上角 × 按钮“收走”便笺；可从菜单栏“已收走”恢复。
- 设置中可选择左右停靠、宽度、显示器、跨桌面显示和保持置顶。
- 内容较多时，整个便笺列可以滚动。

## 苹果备忘录

在备忘录中选中一篇笔记，再从桌边菜单选择“贴上备忘录中选中的笔记”。本地便笺也可以通过右键“保存到苹果备忘录并关联”写入默认账户的“桌边”文件夹。

首次使用可能需要在系统提示中允许桌边访问备忘录。允许后可从菜单手动重试。支持回写格式的关联便笺会在停止输入约 1.5 秒后尝试同步，并每 5 秒检查远端变化；启动、点击图标或快捷键展开、电脑唤醒时立即检查。连接失败时仍保留本地数据。

支持标题、小标题、加粗、斜体、删除线、嵌套项目列表、从 1 开始的常规编号列表，以及正文中可见的网址。正文仍用 Geneva + Fusion Pixel 14 pt 显示，标题对应的备忘录字号单独保留。选中文字后可从“格式”菜单或右键修改；⌘B / ⌘I / ⌘U 分别切换粗体、斜体和下划线。列表回车继续下一项，空列表项回车退出。仅修改格式也会保存并触发同步。

**尚未实现所有格式无损回写。** 当前备忘录脚本接口会漏掉带显示名称的链接地址，也会把相邻的不同类型列表合并、忽略引用及任意 CSS 字号。为保护原文，下划线文字（无法可靠区分普通下划线与隐藏链接）、带显示名称的链接、自定义编号起点、相邻混合列表、引用、任意混合字号/颜色/段落布局，以及表格、勾选清单、图片和附件继续只读。右键菜单显示原因，可打开原备忘录编辑。锁定笔记不导入。

本地便笺可保存下划线、引用和带显示名称的链接等更多格式；支持的 HTML 粘贴会保留样式，不支持的粘贴内容会使用纯文本。把这类本地便笺关联到备忘录时会明确阻止不可靠的回写，保留本地内容。暂未实现 RTF 粘贴保真。

两边都变化时，暂停覆盖并显示 `!`。可以另存当前便笺为新的备忘录，保留原文。同步依靠备忘录脚本接口读取 HTML 并在写入前再次核对；这是轻量同步，并非具备服务端事务的协作编辑系统。

**当前验证状态：** 已使用专用合成笔记验证真实备忘录双向同步、仅格式修改、标题字号、粗体/斜体/删除线、嵌套项目列表、分开的编号列表、可见 URL 参数及两边同时修改格式的冲突保护。纯文本同步也做了回归验证。每次回写前备份原 HTML 与本地富文本，回写后核对逐字样式、标题字号及列表结构；差异会显示同步问题并保留本地原文。此核对覆盖上述支持范围，不代表所有 Notes 格式均已验证。未针对多显示器、全屏应用和不同中文输入法逐一实机验收。

## 数据与备份

本机数据目录：`~/Library/Application Support/DeskNotes/`。

- `notebook.json`：正文、便笺顺序、样式、设置和同步基线。
- `notebook.backup.json`：上次成功保存的副本。
- `sync-backups/`：每次回写前的原备忘录 HTML 和本地富文本备份；目前不自动清理。
- 主文件损坏时尝试恢复有效备份，同时保留损坏文件以便排查。

可在菜单栏导出全部便笺为 Markdown。应用本身不包含遥测、账号系统或网络后端；关联备忘录的内容由所选 Notes 账户负责同步。

动画已用独立空白窗口运行实际 Core Animation 验证：完成回调、重复显示不重启、反向时接续当前透明度、过期回调忽略、淡出后隐藏、减少动态效果模式，以及立即取消动画。原有保存、边缘触发和链接测试全部通过。未读取个人便笺。

## 0.7 即时 Markdown 输入与边缘图标

屏幕入口改为参考 ryOS Stickies 的叠纸、折角、描边和投影，使用原生矢量绘制；没有复制 ryOS 的图片资源。入口点击范围为 44 × 48 个逻辑像素，悬停和按下有轻微位移反馈。

编辑器继续使用 AppKit 原生 NSTextView，直接编辑格式后的内容，没有源码／预览切换。输入 `* `、`- ` 或 `1. ` 后立即进入列表；`# `、`## ` 进入标题，`> ` 进入引用。列表回车继续，空列表项回车退出。普通未格式化段落中闭合的强调符号、行内代码和 Markdown 链接也可自动转换。中文正在组词时不执行转换。

离线集成 **markdown-it 15.0.2**（MIT）解析 CommonMark。粘贴纯文本 Markdown 自动尝试转为原生富文本；已有正文可通过“格式 → 将 Markdown 转为格式”转换选中文字或全文，支持系统撤销。HTML 富文本粘贴优先保留其原有格式。复杂表格、图片及原生模型尚未支持的内容保留为原文，不做部分转换；这并非完整 GFM 所见即所得编辑器。Markdown 本身不会执行脚本或加载网络资源。解析库和许可证随应用及源码分发。

[MarkEdit](https://github.com/MarkEdit-app/MarkEdit) 使用 CodeMirror 6 编辑 Markdown 源码，这次借鉴其使用成熟解析组件的方式；没有嵌入整个 MarkEdit 或替换为网页编辑器。[markdown-it](https://github.com/markdown-it/markdown-it) 是本次实际使用的外部库。备忘录同步的格式保护范围维持前述约束。

## 0.7.1 同步一致性保护

- 写入前将待确认提交持久化；写入结果不明、回读不一致或两边冲突时，暂停状态随笔记保存。重开和继续编辑不会盲目自动重试。
- 同时保存当前本地版本、当次提交以及回读 HTML／文字；原文仍保存在 `sync-backups/`。暂停后“立即同步”只读核对；确认远端与提交或当前本地版本一致时才解除暂停并更新基线。
- 自动检查也遵守 1.5 秒输入稳定期；获取远端后、实际发起写入前再次检查输入与中文组词状态。
- 错误信息区分正文字符、段落数量、空白以及样式／列表差异，不以忽略正文或空行的方式消除报警。
- 点击同步问题可并排查看两份内容。采用远端副本前再次确认它未改变，并先备份本地当前版本；也可保留本地版本，另存并关联。

已验证：暂停与提交／回读副本保存重开、暂停后不自动重试、输入稳定期、正常纯文本／富文本实际双向同步和冲突保护。校验发生在 Notes 接口写入之后，因此它能发现并保留不一致的证据，不能保证 Notes 接口永远不改变内容。旧版未保存报错当刻的回读副本，不能仅凭后来的远端内容确定历史差异发生在哪个环节。

## 0.7.4 加快收起

移出等待从 0.65 秒缩短到 0.25 秒，收起动画从 0.4 秒缩短到 0.2 秒，通常约 0.45–0.55 秒完全消失（包括定时检查间隔）。正文保有焦点不再无限阻止收起；最近 0.35 秒仍有键盘输入、中文组词、拖动和菜单操作时保持展开。仅点击图标展开的规则不变。

## 0.8 五级列表

在项目列表或编号列表中，Tab 将当前项放到前一个同级项下面，Shift+Tab 退回一级，最多五级。需要有前一个列表项作为父项；第一项不会凭空生成父项。第一级 Shift+Tab 保持原状，空项回车仍可退出列表。普通正文的 Tab 保持系统原有行为。

回车继续当前层级，右键“格式”菜单也可增加／减少层级。调整父项时子项整体移动；连续选中同一分支的项目也可一起调整。光标按正文位置保留，操作支持撤销和重做，存储为真实列表结构。

已通过原生编辑器的二至五级 Tab、五级上限、Shift+Tab、回车续写、撤销／重做、父子项移动、光标位置、JSON 保存重开和 HTML 往返测试；专用苹果备忘录笔记已验证五级项目列表的实际双向同步及冲突保护。

## 0.8.1 远端刷新

自动检查缩短为 5 秒，并放入公共运行循环模式，避免菜单跟踪阻挡检查。启动、展开和电脑唤醒时立即检查；每张便笺仍限制单个在途同步，保留输入稳定期与冲突暂停。刷新只读取已关联笔记。备忘录自身的云端延迟仍取决于系统。

## 0.9.0 自由桌面贴纸

按住顶栏拖动，即可将便笺从侧边移出，独立摆放在任意显示器上。桌面贴纸不会随侧边自动收起；右键“收回侧边”可重新收纳。菜单或 ⌃⌥N 可隐藏／恢复全部贴纸，点击边缘图标也可恢复。位置与独立大小自动保存，断开显示器时调整到可见区域。桌面贴纸从右下角调整大小，双击顶栏折叠，× 仍为收走并可从菜单恢复。原有文字、富文本及备忘录关联保持在同一张便笺中。

## 0.9.1 加粗和六级标题

⌘B 对当前编辑器的选区切换加粗，无选区则切换接下来的输入。行首输入 # 至 ###### 加空格，实时转换为一至六级标题（24、21、18、16、15、14 pt）；正文仍为 14 pt。标题回车恢复正文。格式菜单和右键菜单也提供六级标题。三级至六级保存在本地，尚未通过 Notes 回写验证时明确阻止回写，避免静默降级；一、二级沿用已有同步支持。

## 0.9.2 默认隐藏与钉住

默认开启自动隐藏：启动时隐藏未钉住的贴纸，点击边缘图标显示；鼠标离开侧边及未钉住的桌面贴纸约 0.25 秒后收起，桌面贴纸用短淡出动画。编辑、中文输入、拖动和菜单操作仍保持展开。顶栏的钉子按钮可让单张贴纸保持显示，状态自动保存；侧边便笺钉住时独立移到桌面。再次点击取消，收回侧边也会取消钉住。明确的菜单／快捷键隐藏仍可隐藏所有贴纸，包括已钉住的贴纸。

## 0.9.3 首次按下即可拖动

未激活便笺的顶栏直接接收首次鼠标按下，不再需要先点选再拖。折叠标题文字也属于拖动区域；钉子和关闭等按钮保持独立点击。右下角调整大小同样接受首次按下。

## 0.10.0 多显示器

每块屏幕均提供边缘入口；点击后侧边栏移到该屏幕，自由贴纸保留各自位置。拖动途中可跨过屏幕边界，松手后调整到可见区域并保存稳定显示器身份和屏内偏移。断开显示器时临时回到可见屏幕，保留原锚点，重新连接后恢复（若已手动移动，则以新位置为准）。支持显示器左右／上下排列和负坐标，使用 macOS 逻辑坐标适配缩放。设置中的显示器选择针对侧边栏。

验证范围：模拟多屏布局覆盖负坐标、竖屏、屏幕重排、断开／重连、降低分辨率和边界归属，单屏原生窗口验证拖动可越过屏幕边缘。尚未进行真实双屏拔插、不同缩放比例混用或全屏 Space 的实机验收。

## 0.10.1 入口图标拖动

边缘触发图标支持沿当前屏幕边缘上下拖动，松手保存位置，每块显示器独立记录；采用相对位置适配屏幕分辨率变化。单击仍打开便笺，小幅手抖不会误判为拖动，拖动松手不会展开。上下边界限制确保图标始终可见。

## 0.10.2 点击入口后的展开保护

图标及周围 10 pt 纳入已展开状态的鼠标保留区域，即使图标窗口在展开后暂时隐藏，鼠标停在点击位置也不会立即收起。移出后的等待从 0.25 秒增加到 0.65 秒，再进行原有约 0.2 秒淡出。仍由单击展开，悬停不会唤出隐藏便笺。

## 0.10.3 便笺尺寸快捷键

⌘+（也支持 ⌘=）增大当前便笺，⌘− 缩小；每次宽高各调整 32 pt，沿用尺寸上下限并自动保存。快捷键针对当前便笺窗口，正文大小不变；折叠状态下调整的是展开尺寸。右键“便笺大小”中也可找到增大／缩小操作。

## 0.10.4 便笺与文字一起缩放

⌘+／⌘= 与 ⌘− 在调整便笺尺寸时，同步增加／减少 10 个百分点的正文显示比例（80%–200%）。使用原生滚动视图缩放，标题、列表、正文一起变化并重新换行，不修改保存的富文本字号或 Notes 同步格式。缩放比例每张便笺独立保存；恢复默认大小同时恢复 100% 字号。

## 0.10.5 扩大便笺保留区域

侧边栏和自由贴纸四周的保留范围由 10 pt 扩大为 36 pt，鼠标稍微越出纸面时仍保持展开。离开这一圈后继续等待 0.65 秒再收起。此范围仅影响自动隐藏判断，不拦截其他窗口点击，也不会通过悬停唤出隐藏便笺。

## 0.10.6 更宽的保留区域

便笺四周的自动隐藏保留范围从 36 pt 扩大到 72 pt。离开后仍等待 0.65 秒再收起。

## 0.10.7 末行可见性回归修复

修复缩放编辑区重新排版后，滚动位置仍停在旧布局、末行可能落在可见范围之外的问题。输入和可见光标所在行重新排版后，等待原生布局完成，校正编辑区高度并滚动到完整插入行；包括末尾空段落。底部保留 24 pt 显示余量，避免末行紧贴边框和尺寸角标。只在活动编辑器中跟随，手动向上阅读时的后台刷新不拉回末行。

`--last-line-check` 可单独运行，且已加入 `--self-test`：覆盖 80%／100%／120%／150%／200% 缩放、长文末行、空末行、自动换行、中文组合输入与提交、等价格式刷新、窗口变窄后的继续输入、非整数宽度和阅读位置保持。修复前已复现 150%／200%／80% 缩放下的裁切失败，保留诊断于工作目录。
