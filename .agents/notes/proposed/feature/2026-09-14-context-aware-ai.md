# Agent Note: 面向并行工作上下文的 AI 能力

Status: proposed

## Problem

用户希望旁白未来与 AI 结合，帮助处理并行任务的进度与上下文。目前尚未确定具体能力、模型或数据边界。

## Proposal

先设计用户主动触发、范围明确的上下文辅助流程。候选方向为整理当前任务、提炼下一步和恢复工作上下文；这些是待讨论方向，不是已承诺或已实现功能。仓库 Agent Notes 先解决开发协作连续性，与用户便笺数据分开。

## Alternatives considered

待评估本地模型与远端模型、单张便笺与用户选定的多张便笺上下文；尚未形成选择或否决。当前没有授权自动上传全部便笺的设计。

## Acceptance criteria

设计阶段应明确首个用户场景、可读取范围、触发方式、结果预览与撤销、模型及数据流。实现前补充具体交互和验证计划，再评审状态；不能仅凭品牌或文档将其标为 implemented。

## Risks

错误建议、跨任务混淆、私人内容外发，以及 AI 修改与备忘录同步之间的冲突均需在具体方案中处理。当前同步安全约束继续适用，见 [同步决策](../../implemented/architecture/2026-09-14-notes-sync-safety.md)。
