# 旁白 · Aside：产品意图与会话决策

记录日期：2026-09-14。依据：从产品构想到 Aside 0.11.0 发布的开发会话，以及该版本源码。此文是整理后的意图与约束，不是聊天逐字稿。后续需求变化时应更新这里，并留下相应决策记录。

## 要解决的问题

多个工作任务并行时，人容易忘记每件事做到哪里、为什么这样做、接下来要做什么。用户希望把这些进度和上下文留在眼前，快速切换工作，而不是再维护一个需要反复打开的任务管理系统。

产品从「桌边 · DeskNotes」起步，正式命名为「旁白 · Aside」。长期方向是能帮助理解和整理工作上下文的 AI 助手；目前已经交付的是本地原生便笺，AI 功能尚未实现。

## 已确认的产品原则

1. 本地优先、macOS 原生。现有版本以 AppKit/SwiftUI 实现，面向 Apple Silicon、macOS 13+。
2. 轻巧、随手记录。参考 ryOS Stickies 的纸张和像素气质，同时适配 macOS；英文 Geneva、中文 Fusion Pixel，正文默认 14 pt。
3. 可自由摆放，又能安静收起。顶栏直接拖动，无需先点选；每张便笺独立保存位置、尺寸和显示缩放。
4. 内容可靠性优先。关联苹果备忘录时保留支持的富文本；发现差异时保留两份内容，而不是追求表面上的“同步成功”。
5. 发现问题后形成回归。用户明确要求末行裁切这类问题进入测试，避免后续迭代反复出现。

## 当前交互约定

| 事项 | 已确认行为 |
|---|---|
| 展开 | 单击边缘图标；不恢复悬停展开。保留 ⌃⌥N 显示/隐藏。 |
| 隐藏 | 未钉住的便笺默认隐藏；移出纸面四周 72 pt 的保留范围后，等待 0.65 秒再淡出。图标原位置也参与已展开状态的保留判断。 |
| 钉住 | 每张便笺有钉子按钮，钉住后常驻；明确的全部隐藏仍可隐藏它。侧边便笺钉住后独立摆放。 |
| 自由摆放 | 顶栏可直接拖动，右下角调整大小，双击顶栏折叠；右键可收回侧边。关闭按钮是收走，可恢复。 |
| 入口位置 | 图标沿当前屏幕边缘上下拖动，每屏分别保存；拖动松手不误展开。 |
| 缩放 | ⌘+ / ⌘= 与 ⌘− 同时调整便笺宽高和文字显示比例；每张独立保存。显示缩放不改 Notes 原始格式。 |
| 多屏 | 每屏入口、跨屏拖动、显示器身份与屏内位置保存；断开后临时回退，重连恢复，手动移动则以新位置为准。 |
| 编辑 | 原生富文本体验；⌘B 加粗，链接可打开，Markdown 输入即时转换。项目列表支持 Tab/Shift+Tab 调整到最多五级。 |
| 标题 | 行首 `# ` 至 `###### ` 转为六级标题。三至六级保存在本地，尚未通过 Notes 回写验证，会阻止该便笺自动回写。 |

图标和便笺周围的保留范围只用于自动隐藏判断，不抢占其他应用的鼠标点击。

## 数据和同步约束

- 关联指定备忘录，通过脚本接口读写；本地自动保存，编辑稳定后尝试同步，并定时检查远端。启动、展开、唤醒时也检查。
- 写入前保留备份，核对远端基线；写后回读比较。两边同时变更或返回内容不一致时暂停覆盖，提供对照、重新核对、采用已审阅远端或另存本地的路径。
- 支持范围包括已验证的标题、强调、删除线、项目列表和部分链接表达。复杂格式、显式别名链接等仍有限制；不能宣称任意 Notes 内容均可无损回写。
- 改名保留旧应用标识、可执行文件、数据目录及已有备忘录文件夹，避免把品牌更新变成数据迁移。

## 已修复并需要守住的退化

即时 bullet 转换、五级列表层次、跨便笺首次拖动、图标点击后立即隐藏、缩放后末行裁切均已有对应测试。末行问题确认过“重新排版后滚动位置未跟上”的复现路径，修复后保留完整输入行及底部余量；不能据此声称所有 macOS 输入法场景都已实测。

## 尚未完成或确认的事项

- AI 的首个具体功能、模型、处理位置、权限范围、收费方式均未选定。不得把“未来结合 AI”扩写成已经确认的自动读取或自动回写方案。
- 多屏坐标、重排、拔插恢复已做模拟测试，尚未记录真实双屏、混合缩放和全屏 Space 的实机验收。
- Intel/通用二进制、Developer ID 签名与公证、安装包发布流水线尚未交付。
- 仓库公开；项目自身源代码许可证尚未选定，第三方授权保留在资源目录。
